# historical-sources

Typed provenance registry for Sumer Reel Forge historical fiction.

Initial scope:

- Oxford ETCSL composition registry for the source traditions used in Chapters 1–3;
- explicit non-ETCSL source placeholders for traditions such as Atrahasis/Igigi and Adapa;
- manuscript chapter/thread source mapping;
- adaptation classifications that distinguish direct source, paraphrase, composite adaptation, fictional bridge, speculative reconstruction and intentional anachronism;
- visual-evidence contracts for later museum/archaeological references;
- validation that prevents fictional or non-ETCSL material from being silently presented as ETCSL provenance.

See `planning/animation-v3-reset/narrative-source-map.md` for the governing policy.
