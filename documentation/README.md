# Documentation

This folder is the canonical documentation home for Sumer Reel Forge.

## Sections

- `studio/`: application architecture, renderer operations, quality gates, and animation pipeline design.
- `projects/blessings-of-sumer/`: project-specific production reference, visual bible, and review notes.
- `diagrams/`: Mermaid source files used by the Markdown documentation.

Planning, sprint scope, roadmap, and backlog files live in `planning/`.
