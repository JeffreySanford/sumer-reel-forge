# Diagrams

This folder contains Mermaid diagrams for the studio architecture and production workflow.

- `system-context.mmd` shows the major user-facing and service boundaries.
- `render-job-sequence.mmd` shows the render lifecycle from approval to asset review.
- `animation-pipeline.mmd` shows the cinematic illustrated animation pipeline.
- `data-ownership.mmd` shows which services own production, render, and asset data.
